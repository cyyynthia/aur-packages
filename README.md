# Cynthia's AUR packages workspace
This repository is the workspace I maintain my AUR packages in. Needs [`devtools`] and [`namcap`].

All packages I maintain strive to comply with the best current practices for Arch Linux packages.

- [Arch RFC11]: Store PGP keys for source file signatures alongside the PKGBUILD
- [Arch RFC16]: Use SPDX license identifiers in PKGBUILD
- [Arch RFC40]: License Package Sources
- [Arch RFC46]: Upstream package sources
- [Arch RFC52]: REUSE for package license linting
